# 知行 · 个人成长计划

一个无需安装、可离线使用的中文单页应用原型，帮助你把感受、阅读与长期目标放进同一个清晰的节奏里。

## 使用方式

直接用浏览器打开 `index.html` 即可开始使用。初次打开时会显示示例内容；随后所有改动都会自动保存在**当前浏览器的本机存储**中。

## 已包含的模块

- 每日心情打卡：五级心情、文字感受、7 天趋势、连续记录和心情手账
- 读书笔记：书名、作者、摘记/感想、标签和星级评分
- 日计划：任务勾选、完成进度和首页聚焦事项
- 月计划、季度计划、年计划：各自独立的任务列表和进度
- 年度愿景：随写随存
- 数据导出：侧栏的“导出数据”可下载完整 JSON 备份
- 恢复示例：可一键清空当前内容并恢复演示数据

## 隐私说明

本版本没有账号、服务器或数据上传功能。内容仅保存在本地浏览器；清理浏览器站点数据会同时清除记录，请定期使用“导出数据”备份。
